## DESIGN SYSTEM

### Color Palette
**Primary:** Black (#000000)
**Secondary:** White (#FFFFFF)
**Accent:** Gray scale for hierarchy
- Light Gray: #F5F5F5 (backgrounds)
- Medium Gray: #666666 (secondary text)
- Dark Gray: #333333 (primary text when on white)

### Typography
**Headings:** Modern sans-serif (Inter, SF Pro, or similar)
- H1: 48-64px, Bold
- H2: 36-48px, Bold
- H3: 24-32px, Semibold
- H4: 18-24px, Semibold

**Body:** Same sans-serif family
- Body: 16-18px, Regular
- Small: 14px, Regular

### Spacing
- Base unit: 8px
- Consistent padding/margin scale: 8, 16, 24, 32, 48, 64, 96, 128

### Breakpoints
- Mobile: 0-768px
- Tablet: 768-1024px
- Desktop: 1024px+

### Interactions
- Hover states: Subtle gray background or underline
- Click states: Brief scale animation (0.98)
- Transitions: 200-300ms ease-in-out
