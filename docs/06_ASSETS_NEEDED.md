## ASSET PREPARATION GUIDELINES

### Images
- **Format:** PNG for screenshots, SVG for diagrams/logos when possible
- **Optimization:** Compress images (TinyPNG, ImageOptim)
- **Naming:** Use kebab-case (basin-architecture.png, not Basin Architecture.png)
- **Size:** Keep under 500KB per image when possible
- **Dimensions:** Provide 2x resolution for retina displays

### Diagrams
- **Simplify:** Remove sensitive/confidential information
- **Clarity:** Ensure text is readable at display size
- **Style:** Black and white or grayscale to match design system
- **Format:** SVG preferred (scalable, small file size)

### Screenshots
- **Anonymize:** Remove sensitive data, customer names, internal URLs
- **Crop:** Focus on relevant parts
- **Annotate:** Add callouts if helpful
- **Quality:** High DPI for clarity
