## RESPONSIVE DESIGN NOTES

### Mobile (<768px)
- Single column layouts
- Hamburger menu navigation
- Stacked stat cards
- Full-width project cards
- Larger touch targets (min 44px)
- Simplified animations

### Tablet (768-1024px)
- 2-column layouts where appropriate
- Condensed navigation
- Grid layouts with 2 items per row
- Moderate spacing

### Desktop (>1024px)
- Full navigation bar
- 3-4 column grids
- Larger typography
- More white space
- Complex hover interactions

---

## INTERACTION PATTERNS

### Hover States
- Cards: Subtle lift + shadow
- Buttons: Background darken
- Links: Underline fade-in
- Images: Slight zoom

### Click/Tap States
- Brief scale down (0.98)
- Visual feedback
- Loading states for forms

### Scroll Animations
- Fade in as elements enter viewport
- Stat counters animate on scroll
- Sticky navigation after scroll
- Progress bar for long pages

### Form Validation
- Real-time validation
- Inline error messages
- Success confirmation
- Clear error states

---

## ACCESSIBILITY

- Semantic HTML5
- ARIA labels where needed
- Keyboard navigation support
- Focus indicators
- Alt text for all images
- Color contrast ratio >4.5:1
- Screen reader friendly
